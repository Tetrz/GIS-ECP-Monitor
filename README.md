Утилита для мониторинга папки с запросами, загруженными из ГИС ЕЦП c помощью программы **[ГИС ЕЦП Экспорт](https://github.com/Tetrz/GIS-ECP-Export)**, и контроля наличия файлов, подлежащих печати.

[![Download](https://img.shields.io/badge/Скачать-установщик-blue?style=for-the-badge&logo=windows)](https://github.com/Tetrz/GIS-ECP-Monitor/releases/latest)

---

## 📌 Описание

Программа автоматически отслеживает наличие новых запросов в указанной папке и уведомляет пользователя через иконку в системном трее.

- Проверка выполняется **ежедневно с понедельника по пятницу**
- Запросы за **выходные и праздничные дни не учитываются**
- Минимальное участие пользователя после настройки

---

## 🚀 Возможности

- Мониторинг папки в фоновом режиме
- Индикация состояния через системный трей
- Быстрый доступ к файлам по двойному клику
- Поддержка праздничных дней (исключения из проверки)
- Автозапуск при старте Windows

---

## 🖥️ Как работает

Приложение запускается и работает в системном трее:

### 🟢 Зеленая иконка
- Запросы за предыдущий рабочий день **найдены**
- Двойной клик открывает файл `Merged.pdf`

### 🔴 Красная иконка
- Запросы за предыдущий рабочий день **отсутствуют**
- Двойной клик открывает папку с запросами

---

## ⚙️ Контекстное меню

Правый клик по иконке в трее:

- **Автозапуск** — включение/отключение запуска с Windows  
- **Выбрать папку с запросами** — настройка рабочей директории  
- **Задать даты праздников** — исключение дней из проверки  
- **Открыть папку с запросами** — быстрый доступ

## 📦 Установка

1. Скачайте установщик из раздела **Releases**
2. Запустите `Setup.exe`
3. Следуйте инструкциям установщика

---

## ▶️ Первый запуск

При первом запуске необходимо:

1. Выбрать корневую папку с запросами из ГИС ЕЦП  
2. Задать даты праздничных дней (при необходимости)
